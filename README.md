## 🕷️ What is Spider GFX Tool?

**Spider GFX Tool** is a free, open-source **Android game booster and GFX tool** for power users and mobile gamers. Pick **any game installed on your phone**, free up RAM, pick the fastest **gaming DNS**, apply an **iPad View / wide-FOV resolution**, monitor **live FPS / CPU / RAM / battery temperature**, and launch — all **without root**, using **Shizuku (Wireless Debugging / ADB)**.

Most tools work for **every Android game**. Only the dedicated **GFX Tool** section (60 / 90 / 120 FPS config packs) is built for **PUBG Mobile** and its regional versions (Global, BGMI, KR, VN, TW, PUBG Mobile Lite / Flash). The UI is built with **Jetpack Compose Material 3**.

> 🔎 **Looking for:** *game booster for all Android games, Android game optimizer without root, GFX tool for PUBG / BGMI, 120 FPS unlocker for PUBG, iPad view tool, Shizuku gaming tool, FPS counter overlay, RAM cleaner for gaming, gaming DNS changer, ping optimizer* — this project covers all of them in one app.

## ✨ Features

| | Feature | What it does |
| :-: | :-- | :-- |
| 🎮 | **Works with all Android games** | Hub, System Engine, Extra Features, Hibernation, HUD, Crosshair and DNS tools work with **any game** you add as a target. Only the **GFX Tool** FPS packs are PUBG-specific. |
| 🚀 | **SmartEngine (Native APIs + Shizuku)** | Combines Android platform APIs (`PackageManager`, `UsageStatsManager`, `WindowManager`, `BatteryManager`) with Shizuku IPC to run privileged shell commands (`am force-stop`, `dumpsys battery`, `cp`) with parcel-error sanitization and multi-package dispatching. |
| 🎯 | **60 / 90 / 120 FPS Config Packs** *(PUBG family only)* | Downloads versioned release packs from GitHub, verifies ZIP signature, protects against **Zip Slip**, then replaces config files in the game's `/files/` directory via Shizuku. |
| 🎯 | **Hub Target Lock & Launch** *(any game)* | Auto-detects installed games or lets you add and lock any app as target. Runs a Turbo Reactor sequence (RAM purge, cache optimization) and launches the game. |
| 🛡️ | **Gaming Space Overlay** | In-game dock (`TYPE_APPLICATION_OVERLAY`) with touch-passthrough, live telemetry and quick actions. |
| 📊 | **Real-Time HUD** | Floating overlay for **FPS, CPU, RAM and battery temperature**. |
| ➕ | **Draggable Crosshair** | Movable custom crosshair overlay (`CrosshairService`). |
| 📱 | **iPad View / Custom Aspect Ratio** | Custom resolution & landscape width matrices for a wider field of view on supported densities. |
| ❄️ | **Background Hibernation & RAM Sweeper** | Force-stops background apps before launch, with a **Whitelist Manager** to protect apps you choose. |
| 🌐 | **Smart DNS Switcher** | Parallel latency test of Cloudflare `1.1.1.1`, Google `8.8.8.8`, Quad9 `9.9.9.9`, AdGuard — picks the fastest. |
| 🌡️ | **Battery Safety Watchdog** | Resets battery overrides (`dumpsys battery reset`) on charger connect/disconnect and on app launch/exit. |
| 🎨 | **Cyberpunk UI** | Fully custom Material 3 design system, dark theme, smooth animations. |
| 🔓 | **No Root** | Works through Shizuku + Wireless Debugging. Root users can start Shizuku in one tap. |

## ⬇️ Download & Install

1. Go to the **[Latest Release](https://github.com/GfxGamerLab/spider-gfx-tool/releases/latest)** page.
2. Download `app-release.apk`.
3. Allow **Install unknown apps** for your browser/file manager when prompted.
4. Install and open **Spider GFX Tool**.

> ✅ **Only download from this official repository's Releases page.** Fake copies of tools like this exist on random sites and Telegram channels and can contain malware. Always check that the link starts with `github.com/GfxGamerLab/`.

**Requirements:** Android 7.0+ (API 24), `arm64-v8a` or `armeabi-v7a`, Shizuku installed.

## ⚙️ Setup (Shizuku, No Root)

1. Install **Shizuku** from Google Play or [GitHub](https://github.com/RikkaApps/Shizuku).
2. Enable **Developer Options**: `Settings → About Phone →` tap **Build Number** 7 times.
3. In Developer Options, turn on **Wireless Debugging** (connect to Wi-Fi first).
4. Open **Shizuku → Pairing** and enter the 6-digit pairing code.
5. Tap **Start** in Shizuku.
6. Open **Spider GFX Tool → Activation Screen** and **grant Shizuku permission**.

> **Rooted (Magisk / KernelSU):** you can start Shizuku directly with root access.
> **Note:** On many devices Shizuku must be restarted after a reboot.

## 🕹️ How to Use

1. **Activate** Shizuku (see above).
2. Open the **Hub**, tap **Deploy New Target** and lock **any game** you want to boost.
3. *(PUBG family only)* Open **GFX Tool**, choose your region and apply **60 / 90 / 120 FPS**.
4. Optional (all games): **System Engine** boost, **Auto-DNS**, **iPad View**, **HUD**, **Crosshair**, **Hibernation / RAM Sweeper**.
5. Tap **Launch** — the app prepares your device and starts the game.
6. Use **Reset** in the app any time to revert temporary changes.

| `SmartDnsManager.kt` | Parallel DNS latency benchmark. |
| `SystemTelemetryViewModel.kt` | Live hardware metrics via `StateFlow`. |

## 🧯 Troubleshooting

| Problem | Fix |
| :-- | :-- |
| **"Shizuku not running"** | Open Shizuku and tap **Start** again. Re-pair if Wireless Debugging was turned off. |
| **Shizuku stops after reboot** | Normal on non-root devices — restart it after each reboot. |
| **Wireless Debugging won't pair** | Connect to Wi-Fi, keep the pairing dialog open, and enter the code within seconds. |
| **Config not applied** | Make sure the correct game is locked, the game is fully closed, and Shizuku permission is granted. |
| **Overlay not showing** | Enable *Display over other apps* for Spider GFX Tool. |
| **Device gets hot** | Switch to 60/90 FPS, lower graphics, take breaks. Never disable thermal protection. |
| **App is killed in background** | Disable battery optimization for the app (Settings → Battery). |

Still stuck? [Open an issue](https://github.com/GfxGamerLab/spider-gfx-tool/issues/new) with your **device model, Android version, Shizuku version and logs**.

## ❓ FAQ

<details>
<summary><b>Which games does it support?</b></summary>
Most features (Hub, System Engine, Extra Features, Hibernation, HUD, Crosshair, DNS) work with <b>any Android game</b>. The <b>GFX Tool</b> FPS packs are for the PUBG Mobile family: Global, BGMI, KR, VN, TW and PUBG Mobile Lite / Flash.
</details>

<details>
<summary><b>Does Spider GFX Tool need root?</b></summary>
No. It uses Shizuku with Wireless Debugging (ADB). Root is optional.
</details>

<details>
<summary><b>Is it free and open source?</b></summary>
Yes — MIT license, no ads, no paid features.
</details>

<details>
<summary><b>Can it get my account banned?</b></summary>
Modifying game files or using unsupported configs may violate a game's Terms of Service, and game publishers can take action at any time. <b>No tool can guarantee ban safety.</b> Use at your own risk, preferably on a secondary account.
</details>

<details>
<summary><b>Will 120 FPS work on every phone?</b></summary>
No. The game and your device hardware decide the maximum supported frame rate. The config only applies the setting; it cannot add support the device doesn't have.
</details>

<details>
<summary><b>Is it safe? Where do I download it?</b></summary>
Only from the <a href="https://github.com/GfxGamerLab/spider-gfx-tool/releases">official Releases page</a>. The source code is public so anyone can audit it.
</details>

<details>
<summary><b>How do I undo the changes?</b></summary>
Use the in-app <b>Reset</b>, restore the game's original config by clearing the game's data/reinstalling, and reset resolution/DNS from the app.
</details>
